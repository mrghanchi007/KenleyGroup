# Kenley Group — Website

Official website for **Kenley Group Ltd** — an award-winning provider of supported and semi-independent accommodation for care leavers, vulnerable young people and adults across Cambridgeshire and surrounding regions.

**Tagline:** Stable Homes Built on Love

## Tech Stack

- [Next.js 15](https://nextjs.org/) (App Router)
- [Tailwind CSS 3](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/) — intro animation & scroll effects

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Production

```bash
npm run build
npm run start
```

## Pages

- `/` — Home (intro animation, hero, stats, who we support, gallery, network, testimonials, FAQs)
- `/about` — Story, mission/vision, values, leadership, compliance
- `/referrals` — Residents & referrals, criteria, 7-step process
- `/services` — Support services (6 categories)
- `/community` — Community & partnerships
- `/landlords` — Landlord leasing programme & property portfolio
- `/careers` — Careers
- `/contact` — Contact details & enquiry form
